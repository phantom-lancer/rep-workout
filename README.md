# REP — персональный трекер отжиманий

Минималистичное PWA для одного человека: план тренировок, автозапись подходов, отдых с таймером, журнал и статистика. Без серверов, регистрации и облачной синхронизации — все данные живут в IndexedDB на устройстве.

## Ссылки

- Приложение: https://phantom-lancer.github.io/rep-workout/
- Репозиторий: https://github.com/phantom-lancer/rep-workout

## Возможности

- **План цикла**: дни 1–14 — 3 × 13 через день; дни 15–28 — 4 × 13 через день; дни 29–30 — восстановление; день 31 — контрольный тест на максимум. Ручные параметры переопределяют план; автоматического роста нагрузки нет.
- **Тренировка**: счётчик повторений, завершение подхода, отдых 120 секунд с кольцевым таймером, корректировка выполненных подходов, сводка. Всё сохраняется автоматически, незавершённая тренировка восстанавливается после перезагрузки.
- **Уведомления**: напоминание о тренировке в заданное время (только в тренировочные дни, раз в день) и сигнал конца отдыха — через Notification API, без Push и серверов.
- **Журнал**: дата, время, подходы, повторения, длительность, статус.
- **Статистика**: общий объём, личный рекорд, динамика на графике, итоги за 7 и 30 дней.
- **Данные**: экспорт в JSON, импорт резервной копии, полное удаление.

## Установка

### Windows 11 (Edge / Chrome)

1. Откройте https://phantom-lancer.github.io/rep-workout/ в Edge или Chrome.
2. Нажмите значок установки в адресной строке (или «Установить приложение» в настройках REP).
3. Приложение появится в меню «Пуск» и откроется в отдельном окне без адресной строки.

### Android (Chrome)

1. Откройте ссылку в Chrome.
2. Меню → «Установить приложение» (или «Добавить на главный экран»).
3. Значок появится на главном экране, приложение запускается в полноэкранном режиме.

Работает офлайн: после первого открытия кэшируются все ресурсы.

## Разработка

```bash
npm install
npm run dev        # дев-сервер
npm run typecheck  # проверка TypeScript
npm test           # unit-тесты логики плана и статистики
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр сборки
```

Публикация автоматическая: push в `main` запускает GitHub Actions (typecheck → tests → build → GitHub Pages).

## Приватность

Данные хранятся только на устройстве (IndexedDB). Сеть используется лишь для загрузки самого приложения. Никакой аналитики и внешних запросов во время работы.
